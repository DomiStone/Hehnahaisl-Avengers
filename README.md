# Die Hehnahaisl Avengers

Ein kostenloses Browser-Actionspiel zum Erkunden und Teilen. Starte das Spiel unter [hehnahaisl-avengers.github.io](https://domistone.github.io/Hehnahaisl-Avengers/), sobald GitHub Pages aktiviert ist.

## Spielen
- Touch-Joystick / WASD zum Laufen, Maus oder Pfeiltasten zum Umsehen
- Klick: Schlag · Q: Energiestoß · Leertaste: Ausweichen
- Bierkrüge laden die Superkraft. Ton einschalten für Trink- und Rülpsgeräusch.
- E: Superkraft · F: Bewohner retten, Schatz öffnen, Absorber ausschalten
- Journal oder J zeigt Nebenmissionen

Das Spiel läuft direkt im Browser ohne Installation.
